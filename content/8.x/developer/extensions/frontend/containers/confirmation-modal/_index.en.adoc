---
title: "Confirmation Modals"
weight: 10
---

SuiteCRM 8 provides two types of confirmation modals that can be triggered from backend process handlers, async validators, and record logic actions:

* **link:./confirmation-modal[Confirmation Modal]** — a simple dialog with a title, message, and Cancel/Proceed buttons. Used to confirm actions before they proceed (e.g. "Are you sure you want to copy this address?").

* **link:./confirmation-list-modal[Confirmation List Modal]** — a dialog that displays a searchable, paginated table of records. Used when the user needs to review a list of records before deciding (e.g. showing duplicate contacts before saving).
