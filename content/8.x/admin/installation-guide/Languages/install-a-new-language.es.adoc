Si no vas a añadir un nuevo idioma a SuiteCRM, sino que vas a actualizar un idioma
ya instalado, asegúrate de empezar siguiendo la guía correspondiente
link:../update-a-language-pack/[Actualizar paquetes de idioma].
{{% /notice %}}

== Descargar un paquete de idioma

. Elige entre https://sourceforge.net/projects/suitecrmtranslations/files/[Paquetes de idioma estables de SuiteCRM^]
o https://crowdin.com/project/suitecrmtranslations[Últimas compilaciones de paquetes de idioma de SuiteCRM^]

. Elige tu versión e idioma
. Descarga el archivo ZIP
