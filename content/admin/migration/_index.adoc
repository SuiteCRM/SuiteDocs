Migration covers moving to SuiteCRM from a different product, or moving from SuiteCRM 7 to SuiteCRM 8. These are distinct from upgrades — they involve a change of platform or major architecture, not just applying a patch to an existing installation.

== Upgrading vs migrating

[cols="1,1", options="header"]
|===
|Upgrade
|Migration

|Stays on the same major version (7.x to 7.x)
|Moves between products or major versions

|Applied as a patch to your existing installation
|Requires a new installation as the destination

|Uses the Upgrade Wizard or CLI upgrade
|Uses a dedicated migration package

|Reversible via backup restore
|Reversible via backup restore, but more involved
|===
