== Обзор

Этот тип поля полезен для добавления в систему документов, электронных таблиц, PDF-файлов или любого другого содержимого в виде файлов.

=== Добавление поля «File»

Все  поля добавляется в систему через  
link:../../../../../admin/administration-panel/developer-tools/#_студия[Студию], доступную в панели администратора.

Для добавления поля выберите в Студии соответствующий модуль и добавьте в него необходимое поле, как это описано в разделе
link:../../../../../admin/administration-panel/developer-tools/#_создание_и_редактирование_полей[Создание и редактирование полей].

В процессе создания поля настройте его параметры, в частности для поля *File* 
настройте следующие основные параметры:

[cols="1s,3a"]
|===
|Параметр |Описание

|Название поля |Название поля, сохраняемое в базе данных. Не должно содержать пробелов и специальных символов.
|Отображаемая надпись |Система заполняет данное поле автоматически, используя указанное название поля как отображаемую надпись, которая видна пользователям при работе с системой. При необходимости вы можете в любой момент поменять это значение.
|Тип хранилища |Параметр определяет, где и как хранятся загружаемые файлы:

* Личные документы
* Публичные документы
* Архивные документы

Дополнительная информация о различиях между этими типами хранения содержится в разделе
link:../../../configuration/file-storage/file-storage-configuration/#_типы_хранилищ[Типы хранилищ].
|Максимальный размер (в байтах) |Указывает максимальный размер файла (в байтах), разрешенный для загружаемых файлов. +
Этот параметр помогает предотвратить загрузку чрезмерно больших файлов. 
Если значение не указано, ограничение определяется
параметром конфигурации *upload_maxsize*.
|Обязательное поле |Если параметр используется, поле становится обязательным, требуя от пользователей загрузки файла перед сохранением записи.
|===

=== Добавление поля в макеты форм

После создания поля его можно добавить в макет формы соответствующего модуля. +
Детально этот процесс описан в 
link:../../../../../admin/administration-panel/developer-tools/#_редактирование_формы_просмотра_формы_редактирования_и_формы_быстрого_ввода[этом] разделе.

=== Загрузка файлов

image:file-upload-area.png[Область загрузки файлов]

Чтобы загрузить файл в поле *File*, перетащите файл в область загрузки или кликните по области загрузки для открытия диалогового окна и выберите необходимый файл. После загрузки файл будет прикреплен к записи.

=== Просмотр файлов

При просмотре файла он будет отображаться в виде ссылки. 
Рядом будет отображаться актуальный размер файла.

Кликните по ссылке с именем файла, если необходимо выгрузить файл.

=== Замена или удаление файлов

Чтобы удалить или заменить существующий файл, в Форме редактирования  щелкните значок «X» рядом с текущим файлом для его удаления.

После удаления файла область загрузки снова появится, позволяя загрузить новый файл.

=== Допустимые типы файлов

По умолчанию загрузка файлов с определенными расширениями ограничена параметром `upload_badext`, настроенного в файле `config.php`.

Если вы попытаетесь загрузить файл с расширением, указанным в этом параметре, загрузка будет заблокирована, и вы получите сообщение об ошибке.
