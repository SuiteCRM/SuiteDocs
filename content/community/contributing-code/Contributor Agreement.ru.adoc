== Где найти Соглашение для участников?

Ознакомиться с Соглашением для участников можно
[здесь](https://cla.suitecrm.com/SuiteCRM/SuiteCRM).

== Что такое Соглашение для участников?

Соглашение для участников — это документ, определяющий условия лицензирования вашего вклада (как разработчика) в проект SuiteCRM.

== Зачем его подписывать?

Мы стремимся к тому, чтобы SuiteCRM стал крупнейшим и лучшим долгосрочным проектом CRM с открытым исходным кодом, доступным всему миру. Для этого нам необходимо обеспечить защиту проекта:

* Соглашение для участников защищает проект, перенаправляя возможные претензии непосредственно на участника, внесшего вклад.
* Это означает, что любые юридические претензии, касающиеся внесенного вами вклада, будут адресованы участнику, а не проекту.
* Соглашение для участников достаточно подписать всего один раз — оно будет распространяться на все ваши будущие pull-реквесты и другие виды вклада в проект SuiteCRM.

== Что дальше?

Если ваш pull-реквест или иной вклад будет принят и включен в проект SuiteCRM, вы получите уведомление по электронной почте.
