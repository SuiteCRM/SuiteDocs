== Голосование за проблемы и запросы на слияние в GitHub

Голосование за проблемы (Issues) и запросы на слияние (Pull Requests) в GitHub — важный способ внести свой вклад в развитие проекта. Голоса помогают нам определять наиболее значимые проблемы и приоритеты для будущих релизов.

Чтобы проголосовать за проблему или запрос на слияние:

* Найдите нужную проблему или запрос на слияние.
* Нажмите на заголовок проблемы или запроса, чтобы открыть его.
* В левом нижнем углу под основным описанием нажмите на значок «смайлик».
* Выберите эмодзи «большой палец вверх».

{{% notice note %}}
Эмодзи, поставленные в комментариях или других сообщениях, в данном случае не учитываются.
{{% /notice %}}

image:32Issue-Voting.gif[Демонстрация голосования за задачу]

Вы также можете отозвать свой голос, нажав на значок «большой палец вверх» (с указанием количества голосов) в основном описании задачи или запроса на слияние.

== Сортировка проблем и запросов на слияние по количеству голосов

Чтобы увидеть самые популярные проблемы или запросы на слияние, вы можете отсортировать их по количеству полученных голосов. Для этого в списке на GitHub выберите вариант «большой палец вверх» в меню сортировки или добавьте следующий параметр в строку фильтра:

[source,console]
----
sort:reactions-+1-desc
