{{% notice warning %}}
Si ya tienes instalada una versión anterior de la traducción, debes eliminar el paquete anterior y subir uno nuevo.
{{% /notice %}}

En resumen, el proceso para actualizar un paquete de idioma es:

. Desinstalar el paquete de idioma antiguo
. Ejecutar una reparación y reconstrucción rápida
. Instalar el nuevo paquete de idioma
. Ejecutar una reparación y reconstrucción rápida
