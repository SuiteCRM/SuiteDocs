== Administration Panel

The Administration Panel lists all the configuration options and settings available to personalise and manage your SuiteCRM. Selecting an option highlights it and shows a short description of what it controls.

image:admin_panel.png[Administration Panel]

[NOTE]
====
You can jump directly to any admin panel using the Admin Multi-menu, without returning to this index page each time. This lets you move between settings more quickly once you know where you are going.
====

image:admin-multi-menu.png[Admin Multi-menu]

The list below describes each setting and links to the relevant documentation.

== Users & Authentication

* link:../../../../admin/administration-panel/users[User Management]
** Create, edit, activate, and deactivate user accounts, and set user type and access.
* link:../../../../admin/administration-panel/roles-and-security-groups[Role Management]
** Define what users can see and do across each module using the role access matrix.
* Password Management
** Set password security rules, automatic password generation, and Two-Factor Authentication.
* link:../../../../developer/integration-api/v8/authentication[OAuth2 Clients and Tokens]
** Create and manage the API clients and the access tokens issued to them for authenticating with the SuiteCRM V8 REST API.
* link:../../../../developer/integration-api/v8/authentication[OAuth Keys]
** Manage the OAuth keys (client ID and secret) used to authenticate external applications with the SuiteCRM V8 REST API.
* link:../../../../admin/administration-panel/roles-and-security-groups[Security Suite Group Management]
** Create and manage groups of users to control which records each team can see.
* link:../../../../user/security-suite-groups[Security Suite Settings]
** Configure system-wide Security Groups behaviour, such as inheritance and additive security.
