= Синхронизация учётных записей входящей почты

При синхронизации учётных записей входящей почты происходит подключение ко всем активным входящим учётным записям электронной почты по протоколу IMAP и устраняются проблемы с синхронизацией. Доступ к нему осуществляется через системное меню: menu:Администрирование[Восстановление > Синхронизация учётных записей входящей почты].

image:image6.png[Синхронизация учётных записей входящей почты]

В списке *Учётная запись входящей почты* отображаются все активные входящие учётные записи, включая персональные. 

[cols="30,70",frame="none", grid="none"]
|===
|image:image7.png[Выбор учётных записей для синхронизации]
|Выберите нужные учётные записи (удерживайте клавишу Ctrl для множественного выбора) и нажмите на кнопку {btn}[Синхронизация]. 
|===

Страница обновится, и на ней отобразится ход выполнения операции.

== Что делает этот инструмент

Для каждой выбранной учётной записи инструмент выполняет следующие действия:

* Подключается к почтовому серверу по протоколу IMAP.
* Загружает информацию из заголовков электронных писем.
* Определяет наличие «осиротевших» писем (присутствующих в БД системы, но отсутствующих на почтовом сервере).
* Обновляет уникальный идентификатор (ID) для каждого письма.
* Устраняет проблемы с синхронизацией.

== Обработка ошибок

Если при обработке одной из учётных записей возникает ошибка, инструмент продолжает работу с остальными учётными записями. Подробная информация о любых возникших ошибках записывается в файл `suitecrm.log`.
