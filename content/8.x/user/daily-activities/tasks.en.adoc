= Tasks

The Tasks module allows you to record, assign, and track action items and to-do items. Tasks can be related to other records so that outstanding actions are visible from the relevant Account, Contact, Opportunity, or Case.

== Key Fields

* *Subject*: the name or description of the task. Required.
* *Status*: where the task stands: Not Started, In Progress, Completed, Pending Input, or Deferred.
* *Priority*: the urgency of the task: High, Medium, or Low.
* *Due Date*: when the task needs to be completed by.
* *Start Date*: when work on the task is expected to begin.
* *Related To*: links the task to a parent record (Account, Contact, Opportunity, Case, etc.) using a relate field. The task appears in the Activities tile on that record while open, and moves to the History tile once closed.
* *Contact*: links the task to a specific Contact record.

== Creating a Task

To create a Task:

. In the module menu, click *Create Task*.
. Complete the fields described above.
. Click *Save*.

== Relationships

Tasks appear in the *Activities* tile within the Relationships section of the record they are linked to. Completed or closed tasks move to the *History* tile.

For information on working with sub-panels and relationships, see link:../../core-concepts/relationships-subpanels[Relationships and Subpanels].

For standard record operations including searching, editing, duplicating, and importing, see link:../../core-concepts/record-management[Record Management].

== Closing a Task

To mark a task as done, open its Detail View and select *Close* from the *Actions* drop-down.
