== Panel de Administración

El Panel de Administración muestra todas las opciones de configuración y ajustes disponibles para personalizar y gestionar su SuiteCRM. Al seleccionar una opción, esta se resalta y se muestra una breve descripción de lo que controla.

image:admin_panel.png[Panel de Administración]

[NOTE]
====
Puede acceder directamente a cualquier panel de administración mediante el Multi-menú de Administración, sin necesidad de volver a esta página de índice cada vez. Esto le permite moverse entre los ajustes con mayor rapidez una vez que sabe dónde se encuentra cada opción.
====

image:admin-multi-menu.png[Multi-menú de Administración]

La siguiente lista describe cada ajuste y enlaza con la documentación correspondiente.

== Usuarios y Autenticación

* link:../../../../admin/administration-panel/users[Gestión de Usuarios]
** Cree, edite, active y desactive cuentas de usuario, y establezca el tipo de usuario y el acceso.
* link:../../../../admin/administration-panel/roles-and-security-groups[Gestión de Roles]
** Defina lo que los usuarios pueden ver y hacer en cada módulo mediante la matriz de acceso de roles.
* Gestión de Contraseñas
** Establezca las reglas de seguridad de las contraseñas, la generación automática de contraseñas y la Autenticación de Dos Factores.
* link:/developer/integration-api/v8/authentication[Clientes y Tokens OAuth2]
** Cree y gestione los clientes de la API y los tokens de acceso emitidos para autenticarse con la API REST V8 de SuiteCRM.
* link:/developer/integration-api/v8/authentication[Claves OAuth]
** Gestione las claves OAuth (ID de cliente y secreto) utilizadas para autenticar aplicaciones externas con la API REST V8 de SuiteCRM.
* link:../../../../admin/administration-panel/roles-and-security-groups[Gestión de Grupos de Security Suite]
** Cree y gestione grupos de usuarios para controlar qué registros puede ver cada equipo.
* link:../../../../user/security-suite-groups[Ajustes de Security Suite]
** Configure el comportamiento de los Grupos de Seguridad a nivel de sistema, como la herencia y la seguridad aditiva.

== Sistema

* link:../../../../admin/administration-panel/system/#_ajustes_del_sistema[Ajustes del Sistema]
** Configure ajustes de interfaz a nivel de sistema, como el nombre del sistema, el logotipo y los registros mostrados por página.
* link:../../../../admin/administration-panel/system/#_monedas[Divisas]
** Añada y gestione las divisas disponibles en todo SuiteCRM.
* link:../../../../admin/installation-guide/language-management[Idiomas]
** Instale y gestione los idiomas disponibles en SuiteCRM.
* link:../../../../admin/administration-panel/system/#_configuración_regional[Configuración Regional]
** Establezca los formatos de fecha, hora, divisa, número y nombre a nivel de sistema.
* Ajustes de PDF
** Elija el motor utilizado para generar documentos PDF.
* link:../../../../admin/administration-panel/system/#_búsqueda_global[Ajustes de Búsqueda]
** Controle qué módulos aparecen en la búsqueda global y el orden de los resultados.
* link:../../../../admin/administration-panel/search/elasticsearch[Elasticsearch]
** Configure la búsqueda de texto completo mediante Elasticsearch para una búsqueda más rápida y potente.
* link:../../../../admin/administration-panel/system/#_planificador_scheduler[Planificadores]
** Vea, programe y gestione las tareas automáticas en segundo plano que mantienen SuiteCRM en funcionamiento.
* Temas
** Establezca el tema predeterminado y las opciones de apariencia de SuiteCRM.

** Vea y envíe los correos de campañas salientes que están en espera en la cola.
