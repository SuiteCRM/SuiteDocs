= Prise en main

== Se connecter à SuiteCRM

SuiteCRM vous permet de vous connecter à l'aide de votre nom
d'utilisateur et de votre mot de passe, fournis par votre
administrateur système.

image:190Home_screen.png[title="Écran d'accueil"]

image:02Login_with_language.png[title="Sélection de la langue"]

Avant de vous connecter à SuiteCRM, vous pouvez sélectionner la
langue que vous souhaitez utiliser. SuiteCRM propose de nombreuses
langues par défaut, et des packs de langues supplémentaires sont
également disponibles pour d'autres langues dans le monde.

Une fois que vous avez choisi votre langue et saisi vos identifiants,
vous pouvez cliquer sur btn:[Log in] pour accéder au CRM.

image:191Log_in.png[title="Connexion"]

== Mot de passe oublié

Si vous avez oublié votre mot de passe CRM et que vous ne pouvez plus
accéder à votre compte utilisateur, vous pouvez utiliser la
fonctionnalité « Mot de passe oublié » pour vous faire renvoyer votre
mot de passe à l'adresse e-mail associée à votre compte utilisateur.
En cliquant sur le lien *« Forgot Password? »* du formulaire de
connexion, le formulaire de mot de passe oublié s'affichera.

image:179Forgot_password.png[title="Mot de passe oublié"]

Dans ce chapitre, nous avons montré comment accéder à SuiteCRM à

récupérer le mot de passe d'un utilisateur en cas de perte ou
d'oubli.

Dans le prochain chapitre, nous aborderons l'assistant de
