= Конфигурация

В разделе рассматриваются файлы конфигурации, используемые для настройки и расширения функциональности SuiteCRM 8. Эти файлы обычно находятся в папке `config/services/` или переопределяются в папке `extensions/` и файле `config_override.php`.
