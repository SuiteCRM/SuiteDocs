Esta sección cubre la actualización entre versiones de SuiteCRM 7.x. Cada actualización aplica un paquete que parchea su instalación existente en el mismo lugar.

{{% notice info %}}
**¿Va a pasar a SuiteCRM 8?** Eso es una migración, no una actualización, y requiere pasos distintos.
Consulte link:../migration/to-suitecrm-8[Migrar a SuiteCRM 8].
**¿Viene de SugarCRM CE?** Consulte link:../migration/from-sugarcrm-ce[Migración desde SugarCRM CE].
{{% /notice %}}

== Antes de empezar

Revise la página link:before-you-upgrade[Antes de Actualizar] antes de hacer cualquier otra cosa. Cubre las copias de seguridad, la configuración de PHP y los requisitos de permisos de archivos que se aplican a ambos métodos de actualización.

== Elegir un método de actualización

Puede actualizar SuiteCRM 7 utilizando el Asistente de Actualizaciones en la interfaz de usuario o el método CLI desde la línea de comandos en su servidor. La siguiente tabla destaca las diferencias clave entre ambos métodos para ayudarle a decidir cuál se ajusta mejor a sus necesidades.

[cols="1,1", options="header"]
|===
|Asistente de Actualizaciones (interfaz de usuario)
|Actualización por CLI

|Guiado, basado en el navegador
|Se ejecuta desde la línea de comandos

|Adecuado para instancias más pequeñas (menos de ~10.000 registros por tabla)
|Recomendado para bases de datos más grandes o si el asistente se agota por tiempo de espera

|Requiere aumentar los límites de subida de PHP
|Evita las restricciones de tiempo de espera y tamaño de subida del servidor web

|Disponible en todas las versiones 7.x
|Requiere SuiteCRM 7.11.3 o posterior para el comando `robo`
|===

* link:upgrade-wizard[Asistente de Actualizaciones] — guía paso a paso de la interfaz de usuario
* link:cli-upgrade[Actualización por CLI] — guía de línea de comandos

== Rutas de actualización

Actualice siempre de forma incremental a través de los pasos de versión compatibles. No omita versiones menores principales — consulte las notas de la versión de cada versión por la que pase para identificar los pasos manuales necesarios.

Los paquetes de actualización están disponibles en la link:https://suitecrm.com/releases/[página de descargas de SuiteCRM].

== Compatibilidad

Antes de descargar un paquete de actualización, verifique que su versión de PHP, base de datos y servidor web son compatibles con la versión de destino. Consulte la link:../compatibility-matrix[Matriz de Compatibilidad].
