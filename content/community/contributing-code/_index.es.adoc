== SuiteCRM es un proyecto de Comunidad de código abierto

Queremos que todo el mundo pueda contribuir a SuiteCRM, sin importar el
conocimiento técnico que tenga. Ya seas un consumidor sin experiencia técnica,
un recién graduado buscando un nuevo proyecto en el que iniciarse, o un
desarrollador veterano – ¡todos sois bienvenidos a mantener nuestro título
del mejor CRM de código abierto del mundo!
