This section covers migrating an existing SuiteCRM 7 instance to SuiteCRM 8. This is a migration, not an upgrade — it involves setting up a new SuiteCRM 8 environment and moving your SuiteCRM 7 data into it.

{{% notice info %}}
**Upgrading within SuiteCRM 8?** If you are already on SuiteCRM 8 and want to move to a newer 8.x version, see link:../upgrading[SuiteCRM 8 Upgrade].
{{% /notice %}}

== Version prerequisites

Before migrating, your SuiteCRM 7 instance must be on the latest 7.14.x version. Upgrade your SuiteCRM 7 instance fully before starting this process.

Check the link:../compatibility-matrix[Compatibility Matrix] to confirm your server environment is supported by the target SuiteCRM 8 version.
