В этом разделе описывается процесс обновления между версиями SuiteCRM 7.x. Каждое обновление выполняется путем применения пакета, который вносит исправления непосредственно в существующую установку.

{{% notice info %}}
**Переходите на SuiteCRM 8?** Это не обновление, а миграция, требующая выполнения других действий, описанных в разделе
link:../migration/to-suitecrm-8[Миграция на SuiteCRM 8]. +
**Если переходите с SugarCRM CE** - обратитесь к разделу
link:../migration/from-sugarcrm-ce[Миграция с SugarCRM CE].
{{% /notice %}}

== Перед началом работы

Прежде чем приступать к каким-либо действиям, ознакомьтесь со страницей link:before-you-upgrade[Подготовка к обновлению^]. В ней содержится информация о создании резервных копий, настройках PHP и требованиях к правам доступа к файлам — эти сведения актуальны для обоих способов обновления.

== Выбор способа обновления

Обновить SuiteCRM 7 можно двумя способами: с помощью *Мастера обновлений* (Upgrade Wizard) в пользовательском интерфейсе или через интерфейс командной строки (CLI) на сервере. В таблице ниже приведены основные различия между этими методами, которые помогут вам выбрать наиболее подходящий вариант.

[cols="1,1", options="header"]
|===
|Мастер обновлений (UI)
|Обновление через командную строку (CLI)

|Пошаговое обновление через интерфейс браузера
|Выполнение через командную строку

|Подходит для небольших экземпляров (менее 10 000 записей на таблицу)
|Рекомендуется для крупных баз данных или в случаях, когда *Мастер обновлений* завершается по тайм-ауту

|Требует увеличения лимитов на загрузку файлов в PHP
|Позволяет избежать ограничений веб-сервера по тайм-ауту и размеру загружаемых файлов

|Доступно во всех версиях 7.x
|Требует наличия SuiteCRM 7.11.3 или более новой версии для использования команды `robo`
|===

* link:upgrade-wizard[Мастер обновлений] — пошаговое руководство в графическом интерфейсе
* link:cli-upgrade[Обновление через командную строку (CLI)] — руководство по обновлению через командную строку

== Пути обновления

Всегда выполняйте обновление поэтапно, переходя через поддерживаемые промежуточные версии. Не пропускайте основные или промежуточные версии — изучайте примечания к выпуску для каждой версии, через которую вы проходите, чтобы выявить возможные действия, требующие ручного выполнения.

Пакеты обновлений доступны  на 
https://suitecrm.com/releases/[этой^] странице.

== Совместимость

Перед загрузкой пакета обновлений убедитесь, что используемые вами версия PHP, база данных и веб-сервер поддерживаются целевой версией.
Детальная информация описана в разделе
link:../compatibility-matrix[Таблица совместимости^].
