//= Установка / обновление языкового пакета

== Скачивание языкового пакета

На данный момент доступны следующие публичные пакеты русификации: ::
* https://github.com/likhobory/SuiteCRM-CoreRU[Russian RAPIRA Language Pack^]
* https://sourceforge.net/projects/suitecrmtranslations/files[Альтернативный перевод на русский язык^],
 осуществляющийся всеми желающими на основе языковых файлов RAPIRA на сайте
 https://crowdin.com/project/suitecrmtranslations[crowdin.com^] 

{{% notice note %}}
В языковом пакете RAPIRA используется та же терминология, что и в данном руководстве, с другой стороны - альтернативный пакет обновляется несколько чаще. Окончательный выбор по использованию того или иного пакета остаётся за пользователями системы. 
{{% /notice %}}

{{% notice info %}}
Если используется файловая система, чувствительная к регистру символов, то возможно использование обеих пакетов, поскольку имена языковых файлов отличаются по регистру: в файлах RAPIRA используется суффикс *ru_ru*, в альтернативном переводе - *ru_RU*.
{{% /notice %}}

== Установка языкового пакета

 . Откройте панель администрирования.
+
image:image1.png[Открытие панели администратора]
+
 . Установите скачанный пакет в систему, как это описано в разделе 
link:../../../../admin/administration-panel/developer-tools/#_загрузчик_модулей[Загрузчик модулей].

==  Изменение языка интерфейса

Выйдите из системы и войдите в систему заново, предварительно выбрав необходимый язык на странице ввода логина/пароля. +
Выбранный язык будет использоваться в качестве языка по умолчанию.

image:image2.png[Выбор языкового пакета]

При необходимости можно изменить язык интерфейса, не выходя из системы. 
Для этого в *Профиле пользователя* перейдите на закладку *Дополнительно*, в подразделе
link:../../../user/getting-started/managing-your-profile/#_региональные_настройки[Региональные настройки]
 выберите необходимый язык интерфейса системы и нажмите на кнопку {btn}[Сохранить]. +
Выбранный таким образом язык НЕ будет использоваться в качестве языка по умолчанию.


== Обновление языкового пакета

 . Перед установкой обновлённого языкового пакета обязательно удалите ранее установленный пакет, как это описано в разделе 
link:../../../../admin/administration-panel/developer-tools/#_включениеотключение_установленного_модуля[Деинсталляция модуля].

 . Установите новый языковой пакет, как это описано выше.

 . В панели администратора выполните 
link:../../../../admin/administration-panel/system/#_восстановление[быстрое восстановление].
