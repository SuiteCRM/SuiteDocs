== Reportar Incidencias

Una incidencia es un área en la que crees que el proyecto podría mejorarse. Por ejemplo, podrías reportar un problema o error que hayas encontrado al usar el software, o una carencia en la documentación del proyecto.

Al reportar incidencias a través de nuestro repositorio de GitHub, asegúrate de exponer el problema con claridad usando las plantillas de incidencias proporcionadas. Un informe de alta calidad incluye:

* Un título claro y descriptivo.
* Una descripción completa de los pasos para reproducir el comportamiento.
* La versión o versiones de SuiteCRM en las que se encontró la incidencia.
* Detalles del entorno (versión de PHP, versión de la base de datos, servidor web).
* Entradas de registro relevantes de `suitecrm.log` o de tus registros de errores de PHP.

Un reporte claro permite a los colaboradores y mantenedores identificar, reproducir y resolver la incidencia con facilidad.


== Seguridad

En SuiteCRM Ltd nos tomamos la seguridad muy en serio. Si crees haber encontrado una vulnerabilidad de seguridad en nuestro software, repórtala.

{{% notice warning %}}
**Por favor, no reveles públicamente errores de seguridad** hasta que hayan sido gestionados y corregidos por el equipo de seguridad.
{{% /notice %}}

Consulta nuestra link:../../security-policy[Política de Seguridad] para más detalles.

== Etiquetas de GitHub

Las etiquetas ayudan a la comunidad y al equipo de SuiteCRM Ltd a categorizar y priorizar el trabajo. Puedes hacer clic en las etiquetas de abajo para ver la lista actual de incidencias en GitHub.

|btn:[https://github.com/SuiteCRM/SuiteCRM/labels/Priority%3ACritical[Priority: Critical]]| Incidencias que causan pérdida de datos o inutilizan por completo la aplicación.

|btn:[https://github.com/SuiteCRM/SuiteCRM/labels/Priority%3AImportant[Priority: Important]]| Incidencias de alto impacto que afectan a procesos de negocio principales.
