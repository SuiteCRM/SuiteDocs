== Обзор

Синхронизация календаря позволяет пользователю подключить  внешний календарь (Google Calendar или сервер CalDAV) к SuiteCRM. После подключения встречи будут синхронизироваться в обоих направлениях, то есть обновления календаря в SuiteCRM будут синхронизироваться с внешним календарем, а обновления внешнего календаря — с SuiteCRM (двусторонняя синхронизация).

Каждый пользователь настраивает подключение своего календаря в модуле *Учётные записи календаря* (либо через системное меню *Мои настройки*). Администратор системы управляет глобальными настройками синхронизации, а пользователи выбирают и авторизуют конкретный внешний календарь для связи со своей учётной записью в SuiteCRM.


== Основные возможности

* *Подключение внешнего календаря*: Связь календаря Google или сервера CalDAV с SuiteCRM
* *Автоматическая синхронизация*: Автоматическая синхронизация встреч в соответствии с настроенным заданием  Планировщика *Синхронизировать учётные записи календаря*
* *Ручная синхронизация*: Возможность запуска немедленной синхронизации (при необходимости)
* *Просмотр синхронизированных встреч*: Просмотр встреч SuiteCRM, связанных с событиями внешнего календаря


== Начало работы

Первый шаг для настройки синхронизации календаря — это настройка учётной записи календаря. 

Для пользователей Google Календаря::

Начните с 
link:./user-guide[руководства пользователя], где пошагово описаны все необходимые действия.

Для пользователей CalDAV::

. Найдите URL-адрес пользователя в CalDAV, как это описано в 
link:./caldav-guide[руководстве для провайдеров CalDAV].
. Следуйте инструкциям по созданию учётной записи, описанным в 
link:./user-guide[руководстве пользователя].


== Ресурсы для администраторов

Администраторы системы, настраивающие синхронизацию календаря, могут ознакомиться с разделом
link:../../admin/administration-panel/calendar-sync[Руководство администратора] для получения информации о:

* Глобальных настройках синхронизации
* Настройке планировщика
* Настройке поставщика OAuth (для Google Calendar)
* Переходе с устаревшей версии синхронизации с календарём Google

{{% notice note %}}
Прежде чем пользователи смогут подключить свои календари, администратору системы необходимо
настроить планировщик SuiteCRM и (для Google Calendar) провайдера OAuth.
{{% /notice %}}
