== Обзор

SuiteCRM 8 автоматически сохраняет  электронные письма как черновики при закрытии окна электронного письма, гарантируя, что вы не потеряете раннее введённый текст.

Черновики хранятся до тех пор, пока не будут удалены вручную или не будут открыты и отправлены в виде писем.

Черновик сохраняется автоматически при закрытии модального окна создания письма, если хотя бы одно из следующих полей заполнено:

* Текст письма (не считая подписи)
* Тема
* Вложения

== Управление черновиками

=== Уведомление о сохранении черновика

При закрытии модального окна создания письма и сохранении черновика в верхней части экрана на короткое время появляется надпись *Черновик сохранён*, подтверждающая сохранение письма.

=== Ярлык черновиков

[cols="5,1"]
|===
|При сохранении черновиков в правом нижнем углу экрана появляется ярлык, отображающий
текущее количество черновиков или надпись *10+*, если черновиков больше 10.
| image:drafts-button.png[Кнопка «Черновики»]
|===

Нажмите эту кнопку для просмотра списка сохранённых черновиков.

=== Список черновиков

image:draft-list.png[Список черновиков]

В списке черновиков отображаются все сохранённые черновики со следующей информацией:

Получатель:: Отображается либо первая запись в поле *Кому*, либо связанная запись, если она есть в поле *Кому*, либо *Нет получателей*, если получатели не указаны.
Тема:: Начало строки из темы письма или строка *Без темы*, если тема не указана.
Последнее изменение:: Дата последнего изменения черновика.

=== Редактирование черновика

Кликните на ярлык черновиков и выберите необходимый черновик из списка.

При редактировании черновика:

* В заголовке модального окна отображается надпись *Черновик* вместо *Новое электронное письмо*
* В левом нижнем углу появляется значок корзины для удаления текущего черновика
* Черновик не будет учитываться в списке черновиков во время его редактирования

image:draft-edit.png[Редактирование черновика]

=== Удаление черновика

Есть 2 способа удаления черновика:

* Значок корзины, отображаемый в списке черновиков
* Значок корзины в модальном окне при редактировании черновика

=== Закрытие всех черновиков

Нажмите кнопку *Закрыть всё* в верхней части списка черновиков, чтобы удалить все черновики сразу. Перед удалением появится дополнительный запрос на закрытие всех черновиков.

{{% notice note %}}
Черновики, которые в данный момент редактируются, не будут закрыты при использовании кнопки *Закрыть всё*.
{{% /notice %}}

=== Отключение окна черновиков

Если необходимо скрыть ярлык, отображающий окно черновиков, перейдите в раздел menu:Администрирование[Настройка основных параметров E-mail] и отключите параметр *Включить всплывающее окно черновиков*.

При отключении параметра черновики будут сохраняться, но  ярлык, отображающий окно черновиков, появляться не будет.
