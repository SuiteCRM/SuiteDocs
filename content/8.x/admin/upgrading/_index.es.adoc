Esta sección cubre la actualización entre versiones de SuiteCRM 8.x. El proceso de actualización utiliza la herramienta de línea de comandos `bin/console` y aplica el paquete de la versión de destino a su instalación existente.

{{% notice info %}}
**¿Migrando desde SuiteCRM 7?** Pasar de SuiteCRM 7 a SuiteCRM 8 es una migración, no una actualización, y requiere pasos diferentes. Consulte link:../migration[Migración desde SuiteCRM 7].
{{% /notice %}}

== Antes de comenzar

Revise la página link:before-you-upgrade[Antes de Actualizar] antes de hacer cualquier otra cosa. Cubre copias de seguridad, comprobaciones de compatibilidad, requisitos de APP_ENV y permisos de archivos.

== Acciones requeridas

Algunas versiones requieren una acción manual antes o después de actualizar. Compruebe la siguiente tabla para ver si hay pasos que se apliquen a su versión de destino.

== Rutas de actualización

Actualice siempre a través de los pasos de versión compatibles. No omita versiones — consulte las notas de la versión de cada versión por la que pase.

* Actualización de 8.2.x a la última versión: 8.2.x → Actual
* Actualización de RC / 8.0.x / 8.1.x a la última versión: RC/8.0/8.1 → 8.2.x → Actual
* Actualización de Beta a la última versión: Beta → RC/8.0.x/8.1.x → 8.2.x → Actual

== Restricciones de actualización

* Si está en cualquier versión entre 8.0.x y 8.1.x y desea actualizar a 8.3.x o posterior, primero debe actualizar a 8.2.x.
* Hubo un error al actualizar a la versión 8.3.1, resuelto en 8.4.0. Consulte link:troubleshooting/known-issues[Problemas Conocidos] para más detalles.

== Compatibilidad

Antes de descargar un paquete de actualización, verifique que su versión de PHP, base de datos y servidor web sean compatibles con la versión de destino. Consulte la link:../compatibility-matrix[Matriz de Compatibilidad].
