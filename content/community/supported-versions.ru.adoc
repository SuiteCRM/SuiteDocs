== Поддерживаемые версии

Каждый выпуск SuiteCRM поддерживается в течение заранее определенного периода времени после выхода первой стабильной версии. В течение этого срока для системы выпускаются регулярные обновления, содержащие исправления ошибок и уязвимостей.

Для версий категории **ESR (Extended Support Release — выпуск с расширенной поддержкой)** предусмотрен более длительный период сопровождения. По завершении этапа активной поддержки такие версии продолжают получать обновления, касающиеся исключительно безопасности (по мере необходимости). Для версий, не относящихся к категории ESR, период поддержки, ограниченный только вопросами безопасности, не предусмотрен.
